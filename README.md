# أكاديمية أثر | ATHAR ACADEMY 🎓✨

> **"كل بداية صغيرة.. تصنع أثراً كبيراً"**  
> **"نتعلم بحب .. نبني مستقبلاً أرحب"**

منصة تعليمية متكاملة مخصصة للأطفال في مرحلة الطفولة المبكرة (من 3 إلى 7 سنوات)، تركز على التأسيس القوي بأساليب تفاعلية ممتعة ومحفزة.

---

## 🎨 الهوية والتصميم (Brand Identity)
- **الألوان الأساسية:**
  - البني والبرونز الذهبي الفاخر: `#8C6239` (عناوين، أزرار تفاعلية)
  - الذهبي الناعم: `#C59A58` (تمييز ونجوم تفاعلية)
  - العاجي والكريمي الهادئ: `#FAF7F2` (خلفيات مريحة ومناسبة للأطفال)
- **المسارات التعليمية الأربعة:**
  1. 📖 **القرآن الكريم:** تحفيظ وتلاوة وتجويد القرآن بأسلوب مبسط وممتع (من 3 - 7 سنوات).
  2. 🔤 **تأسيس عربي:** تعلّم الحروف وأصواتها وقراءتها مع تدريبات مبسطة وممتعة (من 3 - 7 سنوات).
  3. 🔠 **تأسيس إنجليزي:** تساعد طفلك على اكتساب اللغة بسهولة من خلال القصص والألعاب (من 3 - 7 سنوات).
  4. 🔢 **تأسيس حساب:** تنمي مهارات التفكير والمنطق من خلال أنشطة ممتعة وتفاعلية (من 3 - 7 سنوات).

---

## 🚀 المميزات المنفذة (Key Features)
- **تصميم مطابق للتصميم الأصلي (Pixel-Perfect):** دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).
- **أقسام الصفحة الرئيسية:**
  - **الهيدر التفاعلي:** شعار الأكاديمية الرسمي، روابط التنقل، وقائمة مخصصة للهواتف والأجهزة اللوحية.
  - **الواجهة الترحيبية (Hero Section):** صورة الطفلة المبهجة والملصقات التفاعلية والشعارات التحفيزية.
  - **قسم "رحلة التعلم تبدأ من هنا":** بطاقات المسارات الأربعة مع الفئات العمرية وإمكانية استعراض المنهج كاملاً عبر نافذة منبثقة.
  - **شريط المميزات:** محتوى تفاعلي، معلمون متخصصون، متابعة مستمرة، ودعم جميع الأجهزة.
  - **نشاط تفاعلي حي للأطفال:** لعبة مصغرة لاختبار تفاعل الطفل مع أصوات تشجيعية مركبة عبر (Web Audio API) بدون أي مكتبات خارجية ثقيلة.
  - **حجز حصة تقييم مجانية:** نموذج تفاعلي لولي الأمر لاختيار عمر الطفل والمسار المطلوب.
  - **نظام الحسابات (Auth Modals):** تسجيل الدخول وإنشاء حساب لأولياء الأمور.

## 💻 طريقة التشغيل والمعاينة المحلية (Local Preview)

يمكنك تشغيل خادم التطوير المحلي والمعاينة في المتصفح عبر الأمر:

```bash
python serve.py
```

سيتم فتح المتصفح تلقائياً على الرابط:
`http://localhost:8080`

أو يمكنك ببساطة فتح ملف `index.html` في أي متصفح ويب مباشرة.
